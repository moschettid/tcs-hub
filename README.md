# TCS Hub

A comprehensive hub for theoretical computer science materials and events.

**Live Site:** [https://moschettid.github.io/tcs-hub/](https://moschettid.github.io/tcs-hub/)

## Overview

TCS Hub is a platform for theoretical computer science resources, designed to help enthusiasts discover and access valuable materials in one place.

### Current Features

- **📚 Materials**: A curated collection of TCS resources including textbooks, lecture notes, and online courses. (In progress)

- **🏫 Schools**: Dynamic table of summer and winter schools in theoretical computer science.

- **🌐 Conferences**: Links to comprehensive TCS conference calendars and resources. (In progress)

## Contributing

This project welcomes contributions! Whether it's adding new schools, updating deadlines, or expanding the materials collection, your input helps the TCS community.
